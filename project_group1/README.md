## Data Source

The raw data (`raw_data/world_bank_panel.csv`) comes from the **World Bank World Development Indicators (WDI)**, a publicly available database maintained by the World Bank Group.

- **Access**: [https://databank.worldbank.org/source/world-development-indicators](https://databank.worldbank.org/source/world-development-indicators)
- **Download date**: April 2026
- **Coverage**: 10 countries, 2015–2019

### Variables

| Variable | Description | WDI Indicator Code |
|---|---|---|
| `gini` | Gini index (World Bank estimate) | `SI.POV.GINI` |
| `edu_exp_pct_gdp` | Government expenditure on education, total (% of GDP) | `SE.XPD.TOTL.GD.ZS` |
| `gdp_pc_usd` | GDP per capita (current USD) | `NY.GDP.PCAP.CD` |
| `secondary_enroll` | School enrollment, secondary (% gross) | `SE.SEC.ENRR` |
| `urban_pop_pct` | Urban population (% of total) | `SP.URB.TOTL.IN.ZS` |

## Replication Instructions

### Requirements

All analysis is conducted in **R**. You need the following packages (installed automatically via `pacman`):

```r
install.packages("pacman")
```

The scripts then load: `tidyverse`, `xtable`, `stargazer`, `fixest`, `wesanderson`.

### Steps to Replicate

Run the three scripts **in order** from the `code/` folder (or set your working directory to the project root):

1. **`1_clean_data.R`** — Reads `raw_data/world_bank_panel.csv`, creates derived variables (log GDP per capita, country and year factors), and saves a clean dataset `output/clean_panel.rds`.

2. **`2_descriptive_evidence.R`** — Loads the clean dataset and produces:
   - `output/table1_summary_stats.tex` — Summary statistics table
   - `output/figure1_scatter_edu_gini.pdf` — Scatter plot of education spending vs. Gini
   - `output/figure2_gini_trends.pdf` — Gini trends over time by country

3. **`3_reduced_form.R`** — Loads the clean dataset and produces:
   - `output/table2_ols.tex` — OLS regression results
   - `output/table3_fe.tex` — Country fixed-effects regression results

### Important Notes

- Set the `input` and `output` paths at the top of each script to match your local directory structure before running.
- All output files are overwritten each time the scripts are run.
- Scripts must be run in order: script 2 and 3 depend on the clean data produced by script 1.
